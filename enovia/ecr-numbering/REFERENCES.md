## SDK API

다음은 Dassault 저작권 표시가 있는 SDK API 문서의 공개 미러입니다. 메서드 계약 참고 자료이며 설치 버전 JAR의 호환성 보증이 아닙니다.

- [BusinessObject](https://library.plmcoach.com/enoviajava/Doc/docs/api/matrix/db/BusinessObject.html): lockForUpdate(Context) 확인.
- [DomainObject](https://library.plmcoach.com/enoviajava/Doc/docs/api/com/matrixone/apps/domain/DomainObject.html): ID 생성자, 속성 get/set 확인. getAutoGeneratedName도 있지만 이 구현에서는 이중 발급을 피하도록 호출하지 않음.
- [Context](https://library.plmcoach.com/enoviajava/Doc/docs/api/matrix/db/Context.html): getTransactionType(), TRANSACTION_TYPE_UPDATE 확인. 이 코드 내부에서 commit하지 않는 구조로 작성.
- [Oracle Java 8 Clock](https://docs.oracle.com/javase/8/docs/api/java/time/Clock.html): 시각·시간대 및 고정 시각 검사의 계약.

## 기존 프로젝트

[Shin-JS/jsjavaex/enovia](https://github.com/Shin-JS/jsjavaex/tree/master/enovia)의 기존 위젯 자료를 확인했습니다. master의 참조 커밋은 b387c6a25f3b6273ef22454b6435688d03b86de9입니다. 이 시점에 CA 생성 백엔드 Java/JPO 본체는 없었습니다. 기존 REFERENCES에 기재된 R2024x 저장소의 3dspace 경로는 이번 조회에서 404로 반환돼 백엔드 근거로 사용하지 않았습니다.

EcrNameService 등은 이번에 작성한 클래스입니다. 기존 벤더 클래스와 같은 이름의 가상 구현을 만들지 않았습니다. 실제 수정 대상 클래스·메서드, 카운터 ID, 서버의 사업부 정보 취득 경로는 아직 확인되지 않았습니다.
