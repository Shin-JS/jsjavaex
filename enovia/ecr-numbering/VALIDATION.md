```bash

```

```bash
python3 run_tests.py
```

## 주요 검사

- 0001부터 Z999까지 유일성, 길이, 왕복 변환 및 A000 제외.
- 9999→A001, A999→B001, Z999 초과 거부.
- 5개 사업부, 15자리 name, 한국 날짜 및 Locale 독립 ASCII 숫자.
- 대역을 통한 잠금→읽기→증가 순서, 날짜/사업부별 카운터 연결, 누락·중복 ID·잘못된 값·저장 오류.
- update 트랜잭션 강제, 대상 커스텀 타입의 기존 name 교체.
- 비대상 타입은 구성 조회·카운터 갱신 없이 유지.
- 인증된 Context의 credential/user 사업부 매핑 및 누락·잘못된 매핑 거부.

## 실제 서버에서 남은 확인

- 현재 위젯/커스텀 타입이 확인된 CA adapter를 호출하는지.
- 실제 기존 카운터 ID·속성·이관 시작값, 일자별 준비 상태.
- DB 권한, 다중 WAS에서의 동시 요청, 전체 생성 오류 시 롤백·잠금 해제.
- 기존 CA 생성 후 처리와 분류 저장, 응답 및 UI name 반영.

대역은 Matrix DB 잠금/롤백을 재현하지 않습니다. 실제 SDK 컴파일 통과도 서버 실행 성공과 동일하지 않습니다. 기본 CA를 포함한 실제 위젯 통합 실행은 이 환경에서 수행하지 않았습니다.
