# 변경 조각 검증 범위

기존 파일명의 JS에는 전체 OOTB 코드 대신 추가 함수와 호출 위치 주석만 들어 있습니다. 전체 파일 교체용이나 자동 적용 patch 파일이 아닙니다.

로컬 확인 항목: JavaScript 문법, bridge의 위젯 활성화/타입 조건, 대화상자별 상태 분리, 참고 2024x ENONewWidget.js에 변경 조각을 삽입했을 때의 문법.

현재 사용자 환경에서 확인할 항목: 실제 파일/AMD 모듈 위치, widget.setValue/getValue의 인스턴스별 분리, facet 초기화, 라이브러리 선택 이벤트, 필수 속성 검증, 실제 분류 값 저장, 다른 위젯의 기본 타입 설정 유지.

기존 문서의 별도 신규 모듈 10개 검사 결과는 이 변경 방식의 통합 검증 결과로 사용하지 않습니다.



## 기존 WUX UI로 변경한 부분

- ENONewWidget.js 변경 조각의 JavaScript 문법 검사 통과.
- WUX 컴포넌트 대역을 사용한 동작 검사 통과: 준비 전 비활성화, 클래스 추가 직렬화, 칩 삭제 전달, 분류 탭 변경의 역방향 표시, 별도의 노드 인스턴스, 찾아보기 연결, 구독/컨트롤 정리.
- ClassificationsFacet.js의 실제 AutoComplete/Button 구성과 CSS 클래스, WUXAutoComplete의 selectedItems/disabled 동작 및 TreeNodeModel의 unselect 메서드를 공개 2024x 소스에서 확인.

대역 검사는 실제 WUX 엔진 실행과 화면 검증을 대체하지 않습니다. 설치 환경에서 칩 표시/삭제, 검색, 선택창, 파라미터 수신 구현, 분류 속성 저장을 확인해야 합니다. 이번 변경은 UI 함수와 적용 안내에 한정하고 기존 타입/위젯 활성화 조건은 변경하지 않습니다.



## 클래스 속성 폼 표시 위치 변경

- 추가된 코드 조각의 JavaScript 문법 검사 통과.
- DOM/WUX 대역 검사 통과: move 동작의 속성 탭 표시, 같은 필드 객체와 입력값 유지, 선택/삭제, 종료 시 원래 부모/순서 복원.
- 참고 소스에서 accordeonCon에 기존 ClassifPropWidget이 주입되는 경로, onInnerResize 메서드, 기존 postCreation/saveClassificationFacet 경로를 확인했습니다. 새 저장 모델이나 중복 저장 경로를 추가하지 않았습니다.

실제 ClassifPropWidget/tweaker 실행, 탭 전환 시 입력값 커밋, 필수 속성 검증, 실제 분류 속성 저장 및 최종 화면 크기는 사용자 설치 환경에서 확인해야 합니다. 대역 검사 결과만으로 이 통합 동작이 완료되었다고 판단하지 않습니다.



## move 단일 동작으로 정리

both 분기, 모드 선택 옵션, 활성 탭 전달 함수/호출 안내를 제거했습니다. 기존 폼은 생성 대화상자가 열려 있는 동안 속성 탭에 머무르고, 종료 때 원래 부모와 순서로 복원됩니다. 이번 로컬 검사는 단일 move 동작과 기존 WUX 선택/삭제/종료 처리를 대상으로 합니다. both 구현은 보류 상태입니다.
